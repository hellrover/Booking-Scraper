# Booking-Scraper
Web Scraping & Automated Ingestion Pipeline (Python, Selenium, Snowflake)

Data Acquisition: Engineered a custom web scraper using Python and Selenium WebDriver to extract real-time hospitality data from Booking.com, handling dynamic content and pagination.

Transformation: Developed a data cleaning and transformation layer to convert unstructured web data into structured Pandas DataFrames, ensuring data integrity and type consistency.

Cloud Ingestion: Established a secure connection to Snowflake to ingest processed datasets into custom-designed schemas, implementing Role-Based Access Control (RBAC) to ensure governed data management.
